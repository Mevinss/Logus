# Logus

Русскоязычная платформа для занятий в одной Wi-Fi-сети. Учитель загружает PDF или вставляет текст, готовит и редактирует вопросы, выдаёт версию урока группе и проверяет ответы. Ученик читает материал и сдаёт работу с телефона. Журнал, аналитика и разминки используют одну SQLite-базу.

## Первый запуск в PowerShell

Требуется Node.js 24 LTS и npm. В каталоге репозитория выполните:

```powershell
npm ci
Copy-Item .env.example .env.local
npm run db:setup
npm run build
npm start
```

При первом запуске `db:setup` создаёт учителя `teacher@logus.local`. Случайный пароль сохраняется в `data\teacher-login.txt`. Можно заранее задать `TEACHER_EMAIL` и `TEACHER_PASSWORD` в `.env.local`. Повторный запуск сохраняет существующую учётную запись. Команда `npm run demo` добавляет один пример черновика с двумя готовыми вопросами для показа без ключа ИИ.

## Вход и проведение

Откройте http://localhost:3000 на ноутбуке. Для следующего запуска достаточно `npm start`. Команда печатает адреса сетевых интерфейсов и слушает `0.0.0.0`. Телефон должен иметь доступ к ноутбуку по указанному порту. Если сеть содержит VPN или несколько адаптеров, задайте в `.env.local` адрес вида `PUBLIC_BASE_URL=http://192.168.1.20:3000` и перезапустите приложение. Порт можно задать через `PORT`. Если Windows запросит сетевой доступ, разрешите его для используемой частной сети.

1. В «Группах» создайте группу, добавьте ученика по имени или псевдониму и скопируйте его индивидуальное приглашение. Открытие приглашения устанавливает сессию ученика в браузере телефона.
2. В «Моих уроках» создайте черновик. Загрузите PDF с текстовым слоем или вставьте текст, разделив абзацы пустыми строками. Выберите страницы, подготовьте задания и проверьте цитаты через «Открыть источник».
3. Опубликуйте урок для группы. Ссылку на занятие могут использовать уже вошедшие ученики. Изменения черновика попадут только в следующие проведения.
4. После сдачи проверьте открытые ответы в журнале. Из аналитики откройте проблемный вопрос, подготовьте разминку и выберите получателей. Разминка получает отдельную запись в журнале.

## ИИ и данные

В `.env.local` настройте серверные `OPENAI_API_KEY`, `AI_MODEL` и при необходимости `AI_BASE_URL`. Адаптер вызывает совместимый с OpenAI маршрут `/chat/completions` и ожидает поддержку JSON-ответов. Для генерации передаются выбранные страницы, для подсказки при проверке — вопрос, критерий и ответ конкретного ученика. После изменения настроек перезапустите сервер. Без ключа работают ручные вопросы, проверка и назначение разминок.

`data/logus.sqlite` хранит пользователей, сессии, версии работ, ответы и результаты. Оригиналы PDF находятся в `data/files/`. Чтобы перенести пилот, остановите сервер и скопируйте каталог `data` целиком. Для отдельной базы задайте `LOGUS_DATA_DIR`. База, пароли, приглашения и файлы учащихся исключены из Git.

## Проверки

```powershell
npm run test:api
npm run build
npm test
```

API-тест и браузерный тест используют временное хранилище. Браузерная проверка запускает сервер на свободном порту и проверяет интерфейс с независимыми сессиями. Для разработки используйте `npm run dev`.

## Показ за четыре минуты

- **0:00–1:00.** Заранее добавьте демонстрационный черновик командой `npm run demo`. Покажите источник вопроса, исправьте формулировку, опубликуйте для группы с подготовленным учеником.
- **1:00–2:00.** На телефоне откройте приглашение и урок. Выберите ошибочный вариант, обновите страницу, проверьте сохранение и сдайте работу с открытым ответом.
- **2:00–3:00.** В журнале откройте работу, поставьте балл за объяснение и подтвердите. Сверьте итог на телефоне, откройте ошибочный вопрос из аналитики.
- **3:00–4:00.** Назначьте короткую разминку этому ученику. Выполните её и покажите две отдельные записи с сохранённой исходной оценкой.
